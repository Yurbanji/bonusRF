# bonusRF — «Что мне положено»

Навигатор льгот и мер государственной поддержки в России.

## Текущий статус

Рабочий прототип **0.2** (исходная контрольная дата данных — **14.10.2026**). Перенесён из сохранённой версии проекта. **Юридическая проверка реестра не завершена**: сайт показывает меры, которые стоит проверить, а не гарантирует право на выплату.

## Файлы

- [index.html](index.html) — интерфейс анкеты, предварительный подбор и карточки мер поддержки.
- [benefits-spb-registry.md](benefits-spb-registry.md) — начальный реестр: 9 предварительных мер и одно направление для будущего наполнения.

## Как запустить

Откройте `index.html` в браузере. Для размещения через GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

После включения Pages адрес обычно будет: https://yurbanji.github.io/bonusRF/ (до включения публикации доступность не подтверждена).
