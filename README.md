# bonusRF — «Что мне положено»

Навигатор льгот и мер государственной поддержки в России.

## Текущий статус

Рабочий прототип **0.3** (исходная контрольная дата данных — **14.10.2026**, расширение — **04.11.2026**). Перенесён из сохранённой версии проекта. **Юридическая проверка реестра не завершена**: сайт показывает меры, которые стоит проверить, а не гарантирует право на выплату.

## Файлы

- [index.html](index.html) — интерфейс анкеты, предварительный подбор и карточки мер поддержки.
- [benefits-spb-registry.md](benefits-spb-registry.md) — исходный реестр: 9 предварительных мер и одно направление для будущего наполнения.
- [data/measures-0.3.js](data/measures-0.3.js) — пять дополнительных карточек: ОМС/диспансеризация, налоговые вычеты, две меры Республики Карелия.

## Как запустить

Откройте `index.html` в браузере. Для размещения через GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

После включения Pages адрес обычно будет: https://yurbanji.github.io/bonusRF/ (до включения публикации доступность не подтверждена).
